# HACKTOP — Global Hackathon Discovery and Management Platform

Tagline: Discover. Compete. Collaborate. Build.

Frontend: Next.js + TypeScript  
Backend: NestJS + TypeScript  
Database: PostgreSQL + Prisma  
Architecture: API-driven modular monorepo.

Hacktop is a global hackathon discovery and management platform that centralizes hackathon discovery, external competition aggregation, registration, team formation, project submissions, judging and results.
